# Fygo TV for TizenBrew

Cliente experimental Fygo TV para Samsung Tizen, baseado no comportamento/API observado na versão Android TV 1.3.3.

## Instalar no TizenBrew

Em **Add GitHub Module**, introduzir:

`DewDrop-99/SmartThingsPublic@fygotv-tizenbrew`

O módulo está numa branch dedicada para não interferir com o conteúdo SmartThings do repositório.

Na primeira execução, indicar o IP/hostname local do FygoOS. Por defeito: HTTP 5666 ou HTTPS 5667.

Esta é uma build inicial para validar API, navegação e reprodução na Samsung UE55NU8505T/Tizen 4.0.
